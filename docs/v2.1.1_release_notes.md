# PreCut v2.1.1 Release Notes

**Release Date:** August 29, 2026

---

## What's Changed

**Portable Data Folder** — The application no longer stores its settings and caches in your `Documents` folder. Instead, `settings.json` and the Python bytecode cache are written to a `data/` subfolder located right next to `PreCut.exe`.

This makes the build fully portable: you can drop the `PreCut` folder anywhere (a USB drive, a secondary disk, a project directory) and all configuration stays with the executable rather than being scattered into your user profile.

---

## Upgrade Notes

- On first launch of v2.1.1, a fresh `data/settings.json` is created next to the executable. Your previous settings from `~/Documents/PreCut/data/settings.json` are **not** migrated automatically — copy that file into the new `data/` folder if you want to keep your existing configuration (quality, codec, cookies, EJS, etc.).
- The app must be run from a writable location. Avoid extracting it into protected directories such as `C:\Program Files`, since the `data/` folder needs write access.

---

## Installation

1. Download `PreCut-2.1.1-portable.zip` from the release.
2. Extract it to a writable folder of your choice.
3. Run `PreCut.exe`. The `data/` folder is created automatically on first launch.
