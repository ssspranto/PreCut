# PreCut v2.1.2 Release Notes

**Release Date:** August 29, 2026

---

## What's Fixed

**Startup Crash** — v2.1.1 failed to launch with `NameError: name 'get_data_dir' is not defined`. The function was imported after it was used to configure the pycache directory. The import order has been corrected so the app starts normally.

This is a fix-only release; behavior and the portable `data/` folder layout are unchanged from v2.1.1.

---

## Upgrade Notes

- Same as v2.1.1: run from a writable folder; `data/` is created next to `PreCut.exe` on first launch.
- Copy an existing `~/Documents/PreCut/data/settings.json` into the new `data/` folder to keep prior settings.

---

## Installation

1. Download `PreCut-2.1.2-portable.zip` from the release.
2. Extract it to a writable folder of your choice.
3. Run `PreCut.exe`.
