# PreCut v2.1.0 Release Notes

**Release Date:** July 12, 2026

---

## What's New

**OST Downloader** — Extract audio soundtracks from videos directly into your project. Supports MP3, FLAC, and AAC formats with selectable bitrates (128k–320k). FLAC automatically disables bitrate selection. Files are saved to your project's `OST/` folder.

**Per-Page Settings** — Quality, codec, format, and bitrate selectors are now embedded directly in their respective downloader pages instead of the global Settings page:
- **Clips**: Quality + Codec selectors
- **Proxy**: Quality + Codec selectors
- **OST**: Format + Bitrate selectors
- **Transcript**: Text format selector (Plain Text / Markdown)

**Transcript Export Formats** — The Transcript Generator now supports exporting as `.txt` or `.md` files.

---

## Improvements

**UI Responsiveness** — Added `update_idletasks()` calls across all download panels and transcript generation for immediate UI redraws. Progress bars, speed labels, and logs now update in real-time without lag.

**Modular Architecture** — The monolithic `page_view.py` (1100+ lines) has been split into 7 focused modules (`ui_page.py`, `components.py`, `page_home.py`, `page_transcript.py`, `page_clips.py`, `page_proxy.py`, `page_settings.py`) for better maintainability.

**Settings Page Simplified** — Settings now only contains Cookies and EJS configuration. Reset Defaults still resets all settings globally.

---

## Bug Fixes

- Quality/codec/format/bitrate settings are now saved to config on download action, preventing partial state saves.

---

## Upgrade Notes

- All previous settings are preserved. On first launch, existing quality/codec/format/bitrate values will appear in the new per-page selectors.
- The Reset Defaults button on the Settings page still resets all settings (including those moved to individual pages).
