# PreCut v2.0.0 Release Notes 🎬

This major update introduces one of our most requested features: **Pause & Resume!** We've also overhauled the packaging process and improved stability for long-running downloads.

## 🚀 What's New?

### ⏸️ Pause & Resume Downloads
You can now pause active downloads in both the **Clip Downloader** and **Proxy Downloader**.
- **Instant Pause**: Stops the download immediately while keeping the partial file on disk.
- **Smart Resume**: Picking up where you left off is as simple as clicking "Resume". The app automatically detects the partial `.part` file and continues the download.
- **Visual Feedback**: The download cards now show a clear "Status: Paused" state when interrupted.

### 🧠 Deno as Default EJS Runtime
To make the setup even simpler for new users, **Deno** is now the default JavaScript runtime for solving YouTube challenges. It offers superior performance and stability for modern web challenges.

## 🛠️ Bug Fixes & Improvements

### 🖼️ Thumbnail Reliability
- **Memory Management**: Fixed a bug where video thumbnails would occasionally fail to display or "disappear" due to Python's garbage collection.
- **User-Agent Support**: Added proper headers when fetching thumbnails to prevent being blocked by content delivery networks.
- **Stability Fix**: Added safety checks to prevent crashes if a download panel is closed while a thumbnail is still being downloaded in the background.

### 📦 Improved Distribution
- **Nuitka 2.0 Ready**: Optimized the standalone packaging process with specific flags for `customtkinter`, `PIL`, and `yt_dlp`.
- **Dependency Audit**: Updated `requirements.txt` to include all necessary packages (`customtkinter`, `requests`) for a smoother developer setup.
